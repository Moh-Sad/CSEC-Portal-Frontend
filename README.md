# CSEC Portal - Frontend

A rule-based portal for the Computer Science and Engineering Club (CSEC) at ASTU, featuring hierarchical access control and member management.

## 🛠 Technologies Used

- **Next.js** (React framework)
- **Tailwind CSS** (Utility-first CSS framework)
- **shadcn/ui** (Beautifully designed components)

## ✨ Key Features

### 🔐 Hierarchical Access Control
- Three-tier user hierarchy:
  1. **President & Vice President** (Full access)
  2. **Division Heads** (Department-level access)
  3. **General Members** (Limited access)

### 👥 Member Management
- ✅ Add new members (with email invitation system)
- 🏢 Create/Manage divisions and groups
- 🔍 Member filtering and pagination
- 👤 Profile management

### 🚀 Additional Features
- 📱 Responsive design
- 💅 Modern UI components
- ⚡ Efficient data fetching and state management
